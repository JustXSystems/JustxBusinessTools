JustX Sync Agent - Setup
========================

For non-technical staff (Windows PC):

1. Keep this whole folder together (do not move only one file).
2. Double-click:  Install JustX Sync Agent.cmd
3. Wait for "SUCCESS", then close the window.
4. Open JustX Sync Center in your browser on THIS same PC.
   It should show: Desktop agent Connected.

Optional:
- Check Status.cmd     - see if the agent is running
- Uninstall JustX Sync Agent.cmd  - remove auto-start and files

Notes:
- You do NOT need to install Node.js yourself (it is included).
- Outlook desktop is only needed for Email Outbox -> Open in Outlook.
- Keep this setup zip private (it contains your company agent token).
